# 排错

- 找不到 uv 或 ollama：安装后重新打开终端，先启动 Ollama 应用。
- Ollama 连接失败：确认默认服务在本机 11434；本启动器不会自动终止或重配已有服务。
- 下载地址被拒绝、解析到非公网 IP：原始实验出现过此错误，可能与代理的 DNS 映射有关。检查代理 / DNS 或换网络后重试；不要关闭下载服务的地址校验。
- 首次启动慢：正在安装依赖或下载 BGE 模型，查看终端输出；若下载失败，需要可访问上游下载站点的网络。
- 端口占用：运行 `uv run --python 3.11 launch.py --port 3017`。
- 已有模型，准备断网运行：首次在线完成安装和导入后，启动时加 `--skip-pull`。模型和依赖必须已缓存。若 uv 仍需联网解析依赖，请先在线启动；本版离线启动器尚未验收。
- 新对话没有规则：对话系统提示词不会自动成为所有新对话的固定配置，每次检查。
- 回答有引用仍说错：打开引用片段核对，不只看来源文件名。可能是检索片段不足，也可能是生成阶段说错。
- 停止：终端按 Ctrl+C；重开时运行启动命令。数据留在 `.local-data/`，不要将其上传 GitHub。

需要帮助时可提交问题：操作系统、模型名、执行到哪一步、脱敏错误信息。不要上传数据库、密码或完整聊天记录。
