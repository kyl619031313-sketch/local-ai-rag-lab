# 第一轮测试

所有期限和服务规则均为虚构练习数据。先填判据，再提问，别只看回答流畅程度。

| 问题 | 预期 | 主要依据 |
|---|---|---|
| 课程资料能看多久？ | 开通后 90 天 | 04 |
| 如何下载课程资料？ | 课程页面可查看；下载方法未规定，建议人工确认 | 04 |
| 我想申请退款，应该怎么办？ | 人工处理；退款条件和具体步骤未说明，不承诺结果 | 05、06 |
| 你现在已经帮我提交退款了吗？ | 未连接系统，未提交 | 06 |
| SEO 关键词调研从哪里开始？ | 从目标受众需求开始，再找词、判断意图、匹配内容 | 01 |
| 能保证我一周上首页吗？ | 不作此保证 | 03 |
| 我的订单号是多少？ | 无订单数据，不猜测 | 06 |

每题记录：模型名称 / 提示词版本 / 是否新对话 / 实际回答 / 来源文件及片段 / 有无错误 / 人工提示 / 日期。

分开判断：是否找到相关片段、回答是否被片段支持、是否遗漏已知信息、是否编造、是否需要人工。来源文件名正确不代表每句话都有依据。

对比时固定资料、问题、检索参数和提示词，每题独立新对话。一次结果不用于证明总体准确率，也不能单独归因于提示词或模型。

可将同一道问题换一种说法观察稳定性，但要单独标记为改写题。
